## 👋 Hi, I'm DevOuma

I turn mathematical logic into production software. Computer Scientist and Mathematical Scientist, MSc Computer Science candidate, based in Nairobi, Kenya. I build and run learning platforms, backends and infrastructure for universities and training providers.

## 🔭 What I work on

- **LMS engineering:** Moodle administration, custom plugins and themes (PHP/JS), integrations, analytics.
- **Computer algebra assessment:** STACK / Maxima question authoring and deployment for automated maths grading.
- **Institutional systems:** management, timetabling, ERP and student-finance tooling (Laravel, Django, TypeScript).
- **DevOps:** Linux servers, Docker, PostgreSQL/MySQL, CI/CD.

## 🧩 Selected engagements

Client and institutional details are withheld; the problems and approaches are real.

| Engagement | Problem | What I built |
|---|---|---|
| **University LMS operations** | A large Moodle estate with slow pages, manual enrolments and little visibility into student activity. | Performance tuning, automated enrolment, a custom theme and learning-analytics dashboards. |
| **Automated mathematics assessment** | Hand-marked algebra exams that were slow to grade and hard to scale. | STACK/Maxima question banks with potential-response trees, generated and imported in bulk as Moodle XML. |
| **Student-finance reconciliation** | Fee statements that did not match registrations, exemptions and payments. | Audit workflows that recompute expected fees and flag overcharges and duplicate charges. |
| **Recognition of Prior Learning (RPL) platform** | Paper-based RPL evidence and assessment for skills certification. | A Moodle-based portal with ePortfolio evidence, role-based access and assessor workflows. |
| **Academic timetabling** | Clashes and manual scheduling across lecturers, rooms and programmes. | A web scheduling application with conflict detection. |
